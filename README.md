# Final-Project
ברפוזיטורי זה נמצאים מספר תיקיות וקבצים. 
1. Data_For_YOLO_Model - קישור לאתר בו נמצא הדאטה לאימון מודל היולו
2. Data_for_LSTM_model - תיקיית הסרטונים מהם אצור דאטה לאימון המודל הסופי
3. Labels_For_LSTM_Model - תיוגים ידניים לכל סרטון שאני יצרתי. ישמש ליצירת הדאטה לאימון המודל הסופי
4. Final_Data_for_LSTM_model - הדאטה הסופי שיצרתי מהסרטונים ומתיוגים ידניים. זה הדאטה שעליו מתאמן המודל הרקורסיבי
5. app - כל מה שנדרש להפעלת ממשק המשתמש.
